# Lector de facturas de proveedores (demo)

Demo con **datos ficticios**. No se conecta a nada: ni a SerAuto, ni a Fabric, ni a ninguna base de datos.

Este repositorio solo contiene la página compilada (`index.html`) que publica GitHub Pages y los avisos
de licencias de terceros.

La página lleva dentro bibliotecas de terceros (React, pdf.js, Tesseract/tesseract.js y otras), cada una
con su licencia: ver [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
